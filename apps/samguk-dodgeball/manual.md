## 1. 어떤 게임인가요?

삼국피구는 삼국지 인물로 구성된 진영을 선택해 컴퓨터 팀과 겨루는 **3대3 피구 게임**입니다. 한 장수를 직접 조작하고 나머지 동료는 자동으로 움직입니다. 경기 중 조작 장수를 바꾸거나 동료에게 공을 전달할 수 있습니다.

10.7.3의 진영 선택 목록에는 **38개 진영, 209명 장수**가 등록되어 있습니다. 군공 상점에는 **20종 아이템**이 있으며, 점령전 지도는 **51개 거점**으로 구성됩니다. 게임의 장수 편성·능력·투구 방식·영토 배치는 게임용 설정입니다. [1][8][9][10]

### 세 가지 게임 모드

| 모드 | 진행 방식 | 기억할 점 |
| --- | --- | --- |
| 평가전 | 선택한 상대와 한 경기 | 2분 종료 시 전과로 승부를 판정합니다. |
| 군웅 제패전 | 내 진영을 제외한 다른 진영과 연속 경기 | 현재 목록 기준 37개 상대와 대결합니다. 경기 사이 출전 명단과 보급을 정비할 수 있습니다. |
| 점령전 | 지도에서 인접 거점을 공격하는 턴제 진행 | 기본 15개 진영이 참가합니다. 도시 점령, 방어, 장수 영입과 체력 관리가 중요합니다. |

평가전과 제패전의 본진은 왼쪽, 원정은 오른쪽입니다. 제패전은 경기가 이어지면서 출전 위치가 바뀝니다. 점령전 전투에서는 도시를 지키는 수비군이 본진·왼쪽, 공격군이 원정·오른쪽입니다. [1][10]

## 2. 진영과 출전 장수 선택

진영 목록의 검색창에 진영 이름이나 장수 이름을 입력하면 해당 진영을 찾을 수 있습니다. 진영을 바꾸면 장수 카드와 배경도 해당 진영 색으로 바뀝니다.

장수는 **3명까지 선택**합니다. 이미 3명이 선택되어 있으면 교체할 장수를 먼저 눌러 해제한 뒤 새 장수를 선택하세요. 3명 편성을 완료해야 출전할 수 있습니다. [1]

| 표시·버튼 | 의미와 사용 방법 |
| --- | --- |
| 선발 | 출전 명단의 첫 번째 장수이며, 경기 시작 시 우선 조작하는 장수입니다. |
| 출전 | 선발과 함께 경기에 들어가는 동료입니다. 경기 중 교대해 조작할 수 있습니다. |
| 대기 | 해당 경기 출전 명단에 포함되지 않은 장수입니다. |
| 선발로 | 이미 출전하는 다른 장수를 선발로 바꿉니다. |
| 열전 | 인물의 정사·삼국연의 관련 소개를 읽습니다. |
| 능력 · 균형 / 공격 / 지략 등 | 해당 장수의 기초 능력과 역할을 확인합니다. |
| 기술 | 해당 장수의 특징 기술과 필살기 설명을 확인합니다. |

**열전·능력·기술은 서로 다른 정보창**입니다. 설명을 읽는 것과 실제 출전 명단을 바꾸는 것은 구분되어 있습니다. [1]

## 3. 화면 읽는 방법

**상단 장수창**에는 양 팀의 장수 사진, 이름, 체력과 기 게이지가 표시됩니다. 우리 팀 카드를 누르면 조작 장수 선택 또는 전달이 이루어지고, 상대 카드를 누르면 공격 대상으로 지정할 수 있습니다.

**중앙 표시판**에서는 남은 경기 시간과 양쪽 생존 인원을 확인합니다. 지원병이 들어온 경우 생존 인원과 실제 장수 수를 구분해 보세요. 마지막 실제 장수의 생존 여부가 즉시 승패에 중요합니다.

**경기장 바닥의 선택 표시**는 현재 조작 중인 장수를 알려 줍니다. **하단 상태창**에는 조작 장수의 체력·기, 필살기 준비 상태와 행동 버튼이 표시됩니다. 회피 버튼의 숫자는 진영이 공유하는 남은 재사용 시간입니다. [2][4][6]

10.7.3에서는 **공을 보유한 자세의 팔·손 추가 표현을 사용하지 않습니다.** 공 보유 중 별도의 손 그림이 보이지 않아도, 보유자에게 공이 연결되어 있으면 정상적인 보유 상태입니다. 공 보유 화면 크기는 기본 경기 공 크기를 사용합니다. [5]

## 4. 조작법

### 키보드

| 행동 | 키 | 설명 |
| --- | --- | --- |
| 이동 | W / A / S / D 또는 방향키 | 현재 선택한 장수를 움직입니다. |
| 일반 투구 | J 또는 Enter | 공을 가진 장수가 던집니다. 기 100이면 자동으로 필살기를 사용합니다. |
| 특징 기술 | E | 공과 기 12 이상이 필요합니다. 장수별 사용 제한도 확인하세요. |
| 필살기 | R | 공을 보유하고 기 100일 때 사용합니다. |
| 잡기 | K 또는 Space | 공격 공이 닿기 직전에 사용합니다. |
| 회피 | L 또는 Shift | 이동 방향으로 빠르게 피합니다. 진영 공용 재사용 시간이 있습니다. |
| 순서대로 교대 / 전달 | Q 또는 Tab | 다른 동료를 선택합니다. 우리 팀이 공을 보유 중이면 전달할 수 있습니다. |

| 일시정지 / 계속 | P 또는 Esc | 경기 진행을 멈추거나 다시 이어 갑니다. 정보창이 열려 있으면 닫기 동작이 우선할 수 있습니다. |
| 전체 화면 | F | 전체 화면을 전환합니다. |

### 마우스·터치

우리 팀의 상단 카드를 누르면 해당 장수를 선택하고, 상대 장수 또는 상대 카드를 누르면 조준 대상을 지정합니다. 화면의 **던지기 / 잡기 / 회피 / 특징 기술 / 필살기 / 교대·전달** 버튼도 사용할 수 있습니다.

모바일에서는 **왼쪽 경기 화면을 누르고 손가락을 밀어 이동**합니다. 터치한 위치에 이동 조이스틱이 나타나며, 다른 손가락으로 행동 버튼을 누를 수 있습니다. 장수 카드와 메뉴 위에서는 해당 버튼의 원래 기능이 작동합니다. [2]

### 하단 키 설명 끄기·켜기

진영 선택 후 **경기 설정 → 하단 키 설명** 스위치를 조절하세요. 설명을 꺼도 이동과 행동 버튼 자체는 사용할 수 있습니다. 이 표시 설정은 브라우저 저장이 가능한 환경에서 유지됩니다. 소리와 전체 화면은 화면의 `♪`, `⛶` 버튼으로도 조절할 수 있습니다. [2]

## 5. 공과 공격의 기본 규칙

### 공 줍기와 잡기는 다릅니다

**바닥 공**은 가까이 가면 자동으로 줍습니다. 반면 **날아오는 공격 공**은 적절한 순간에 잡기 버튼을 눌러야 합니다. 공격 공에 맞으면 체력이 줄고, 체력이 0이 된 선수는 퇴장합니다.

벽에 닿아 **회색 데드볼·무효 공**이 된 공은 공격력을 잃습니다. 데드볼 상태를 거쳐 바닥 공으로 전환되면 주울 수 있습니다. 회색 공은 공격 공과 달리 피해를 주지 않습니다. [3][5]

### 조준과 전달

상대를 직접 선택해 집중 공격할 수 있습니다. 목표를 별도로 고르지 않은 상황에서는 게임이 공격 대상을 정합니다.

우리 팀이 공을 가지고 있을 때 다른 동료를 선택하면 공을 전달할 수 있습니다. 공이 없는 상태에서는 조작 장수를 바꾸는 기능으로 사용합니다. 전달로 공격 위치를 바꾸되, **장수 교대로 진영 공용 회피 쿨타임이 초기화되지는 않습니다.** [2][4]

### 일반 투구·특징 기술·필살기

**J 일반 투구**는 기본 공격입니다. 단, **기 100에서 J를 누르면 필살기로 바뀝니다.**

**E 특징 기술**은 기 12를 소모합니다. E를 사용한 장수는 **다음 공격 1회 동안 E를 다시 사용할 수 없습니다.** 그 장수가 J 또는 R로 한 번 공격한 뒤 다시 사용할 수 있습니다. 기다리기, 잡기, 아군 전달만으로는 이 제한이 해제되지 않습니다.

**R 필살기**는 공을 보유하고 기가 100일 때 사용합니다. 사용하면 해당 장수의 기가 소모됩니다. 기 100이어도 **E는 E 특징 기술**이며, 자동으로 R 필살기로 바뀌지 않습니다. [3]

## 6. 기 게이지

기는 장수마다 따로 관리합니다. 공을 잡거나 주우면 **기본 6에 해당하는 기가 즉시 충전**됩니다. 실제 수치는 해당 장수와 장비의 보정에 따라 달라질 수 있습니다.

**공을 오래 들고 기다려도 시간에 따라 기가 계속 차지는 않습니다.** 아군끼리 패스하는 경우에는 공 획득 보너스를 반복해서 받지 않습니다. [3]

| 기를 얻는 행동 | 기본 보상 |
| --- | --- |
| 새로 공을 획득 | +6을 기준으로 보정 |
| 일반 공격 공 잡기 | +18 |
| 특징 기술 공 잡기 | +20 |
| 필살기 공 잡기 | +24 |
| 분신·보조 공격 공 잡기 | +8 |
| 일반 투구 명중 | +18 |
| 특징 기술 명중 | +20 |
| 필살기 명중 | +8 |
| 한 묶음의 공격이 완전히 실패 | +3 |

위 표의 **잡기 보상과 새 공 획득 보상은 서로 다른 항목**입니다. 한 번 발동한 공격에서 여러 공이 나와도 공격 결과 보상을 무제한으로 중복해서 받는 구조는 아닙니다. 장수 고유의 아군 기 지원 효과는 별도로 작동할 수 있습니다. [3]

필살기는 잡기 시작 직후의 더 엄격한 타이밍에 맞춰야 잡힙니다. 잡기에 성공하더라도 일부 충격 피해가 남을 수 있습니다. 기본 충격은 원래 피해의 8%, 최대 체력의 5% 한도를 기준으로 하며, 보호막과 피해 감소 보정이 적용됩니다. [3]

## 7. 회피와 진영 공용 쿨타임

회피는 **진영 전체가 4.2초의 재사용 시간을 공유**합니다. 한 장수가 사용하면 다른 장수로 바꾸어도 남은 시간이 이어집니다.

여기서 4.2초는 항상 흐르는 현실 시간이 아닙니다. 다음 조건에서는 남은 시간이 줄어들지 않습니다. [4]

| 우리 진영 기준 상황 | 회피 쿨타임 |
| --- | --- |
| 상대 공격 공이 중앙선을 넘어 우리 코트에 들어옴 | 정지 |
| 그 공이 우리 코트에서 날아옴 | 정지 |
| 우리 코트에 바닥 공이 있거나 공이 굴러다님 | 정지 |
| 우리 코트에 데드볼이 있음 | 정지 |
| 우리 팀이 공을 보유함 | 정지 |
| 아군끼리 패스 중임 | 정지 |
| 상대의 보조 공격 공이 우리 코트에 남아 있음 | 정지 |
| 위 정지 조건이 모두 해제됨 | 다시 감소 |

따라서 **공을 잡고 기다리거나 아군끼리 전달해 회피 쿨타임을 채울 수 없습니다.** 상대가 공을 보유하고 있고 우리 코트에 남은 공격·바닥·데드볼 등 정지 요인이 없으면 우리 쿨타임은 다시 줄어듭니다. 양쪽 진영에 같은 기준이 적용됩니다.

쿨타임 정지는 새로운 회피를 충전해 주는 효과가 아닙니다. 이미 남아 있던 시간이 그대로 유지되는 것입니다. 경기를 일시정지하면 경기 진행도 함께 멈춥니다. [4]

## 8. 중앙선 반칙 — 10.7.3의 기준

공을 들고 있는 선수는 중앙선 쪽으로 전진할 수 있지만, **선수의 중심이 중앙선을 확실히 넘어가면 반칙**입니다. 공 자체나 팔·그림 끝부분이 선에 닿았다는 이유만으로 판정하는 방식은 아닙니다.

공을 들지 않은 동료와 수비 중인 선수는 기존 자기 진영 범위 안에서 움직입니다. 동료가 움직인 위치 때문에 공 보유자에게 반칙을 주는 규칙은 아닙니다. [5]

### 반칙이 발생하면

**반칙 위치에서 현재 공을 피해 없는 데드볼로 바꿈 → 상대 코트 방향으로 굴림 → 바닥 공이 된 뒤 상대가 회수**하는 순서로 처리됩니다.

반칙한 선수는 자기 진영 안쪽으로 돌아가며, 화면에 **중앙선 반칙! / 데드볼 · 상대 코트로** 안내가 표시됩니다. 공은 상대 선수 손으로 순간이동하지 않습니다. [5]

## 9. 마지막 장수와 지원병

한쪽 진영의 **실제 장수가 1명만 남으면 지원병 1명**이 합류합니다. 병종은 **창병 / 궁병 / 방패병 중 무작위**입니다. 이미 살아 있는 지원병이 있으면 그 병사가 마지막 장수의 보조 역할을 맡습니다.

마지막 장수가 살아 있는 동안 지원병이 퇴장하면 새로운 무작위 병사가 다시 출전합니다. 병사만 계속 쓰러뜨린다고 곧바로 경기가 끝나는 것은 아닙니다.

**마지막 실제 장수가 퇴장하면 지원병이 살아 있어도 그 진영은 즉시 패배합니다.** 이 규칙은 상대에게도 동일합니다. 다만 시간 제한에 도달하면 다음 절의 시간 종료 규칙이 적용됩니다. [6]

## 10. 승패와 시간 제한

한 경기는 최대 **2분**입니다. 상대의 마지막 실제 장수를 퇴장시키면 시간 종료 전에도 승리할 수 있습니다. [6][10]

| 상황 | 판정 |
| --- | --- |
| 한쪽 마지막 실제 장수 퇴장 | 그 진영 패배 |
| 평가전·제패전에서 2분 종료 | 가한 실제 체력 피해 + 남은 체력 합계 비교 |
| 위 합계가 같음 | 가한 실제 체력 피해가 더 큰 쪽 승리 |
| 합계와 피해량이 모두 같음 | 무승부로 재도전 |
| 점령전에서 2분 종료 | 도시를 지키는 수비군 승리 |

시간 판정의 피해 점수는 **실제 체력이 줄어든 양**입니다. 보호막이 흡수한 양이나 상대 남은 체력을 초과한 피해까지 모두 점수로 더하지 않습니다.

10.7.3의 시간 판정은 생존 중인 경기 참가자의 남은 체력을 합산합니다. **지원병이 있을 때도 남은 체력 합계에 영향을 줄 수 있다는 점**과, **마지막 실제 장수 퇴장은 별도로 즉시 패배 조건이라는 점**을 구분하세요. [6][10]

## 13. 군공 상점과 장착

### 군공 얻기

기본 경기 보상은 다음 식으로 계산합니다.

**장수별 남은 체력 비율 × 100을 각각 버린 뒤 합산 + 경기 완료 60 + 승리 100**

예를 들어 세 장수의 체력이 각각 80%, 50%, 0% 남은 채 승리했다면 `80 + 50 + 0 + 60 + 100 = 290군공`입니다. 지원병 체력은 이 장수별 군공 보상 계산에서 제외됩니다. [9]

### 장착은 장수별로 1개

보유 아이템은 최대 3개이며 **출전 1번 장수 ↔ 1번 아이템, 2번 ↔ 2번, 3번 ↔ 3번** 순서로 적용됩니다. 하나의 장수에게 세 아이템을 모두 중첩하는 방식이 아닙니다. 출전 순서를 바꿀 때는 장비가 적용될 슬롯도 함께 확인하세요.

같은 아이템이나 같은 분류의 아이템을 중복으로 보유할 수 없습니다. 아이템은 보통 **1~2경기용**이며 새 경기에 들어갈 때 사용 횟수가 차감됩니다. 같은 경기를 다시 시작하는 경우에는 중복 차감을 방지하는 처리가 있습니다. 장착한 선수에게는 장비 종류에 따른 표시·효과가 나타납니다. [9]

### 모드별 군공 관리

새 점령전과 새 제패전은 **0군공**으로 시작합니다. 서로 다른 진행의 군공을 합치는 방식은 아닙니다.

점령전 군공·아이템은 그 점령전 기록에 저장됩니다. 제패전 군공·아이템은 연속 진행과 재도전 안에서 유지되지만, 메인 화면 이동·새 시작·새로고침 시 초기화될 수 있습니다. **평가전은 한 경기 모드이므로 상점 구매·다음 진행 이월에 제한이 있습니다.** [11]

게임 내 군공으로만 구매하며 실제 결제는 사용하지 않습니다. [9]

## 14. 점령전 진행과 영입

### 새 점령전 설정

점령전 참가 진영 수의 기본값은 **15팀**이며, 설정 범위는 **8~38팀**입니다. 플레이어 진영도 이 숫자에 포함됩니다. 이 설정은 새 점령전을 만들 때 적용하며, 기존 진행의 참가 진영 수를 도중에 다시 뽑는 기능이 아닙니다.

51개 거점 중 일부는 무주지로 남고, 나머지에 참가 진영이 배치됩니다. 무주지에는 황건 수비병이 있으며 독립적인 진영 턴을 갖고 다른 도시를 공격하지는 않습니다. [10]

### 도시 공격 순서

**내 차례 확인 → 내 출발 도시 선택 → 인접한 상대 도시·무주지 선택 → 출전 명단 확인 → 공격전 시작** 순서로 진행합니다.

한 전체 턴 안에서 진영별 공격·방어 횟수 제한이 있습니다. 방어를 마친 진영은 같은 전체 턴에 다시 공격받지 않도록 보호됩니다. 무주지는 진영 전체가 아니라 **각 거점별로** 방어 여부를 관리합니다. 인접 경로, 차례와 보호 여부를 만족하지 않으면 공격할 수 없습니다.

공격에 성공하면 목표 도시를 점령합니다. **공격에 실패하면 양쪽 영토는 그대로**입니다. 수비에 성공했다고 공격군의 출발 도시를 자동으로 빼앗는 규칙은 아닙니다. [10]

### 체력 관리

점령전에서는 같은 전체 턴의 전투 결과가 이후 편성에 영향을 줍니다. 전투 후 최소 회복 기준은 쉬움 80%, 보통 75%, 어려움 70%이며, 전체 턴이 바뀌면 장수 체력이 회복됩니다. 도시 공격·방어를 이어 가기 전에 출전 명단의 체력을 확인하세요. [10]

### 장수 영입

플레이어가 상대 진영의 마지막 도시를 점령해 멸망시키면 해당 진영 장수를 영입할 수 있는 기회가 열립니다. 군영에서 후보를 확인하세요.

군영은 **기존 장수를 포함해 최대 9명**입니다. 정원이 찼을 때는 영입 장수 사이의 교체가 필요하며, 원래 내 진영 소속 장수를 임의로 하야시키는 방식은 아닙니다. 군영에 9명이 있더라도 실제 경기 출전은 3명입니다. 무주지 수비병은 장수 영입 후보가 아닙니다. [10]

지도에서는 도시 검색, 내 도시·공격 가능 도시 필터, 확대·축소, 도시 목록과 연결선 표시를 활용할 수 있습니다. [10]

## 16. 자주 묻는 질문

### E가 왜 바로 다시 안 되나요?

기 부족뿐 아니라 장수별 1회 공격 제한이 있기 때문입니다. E를 쓴 장수로 J 또는 R 공격을 한 번 진행하세요. 기다리거나 전달하는 것만으로는 제한이 풀리지 않습니다. [3]

### 회피 숫자가 멈춰 있는데 오류인가요?

우리 팀 공 보유, 아군 전달, 우리 코트의 공격 공·바닥 공·데드볼 등은 정지 조건입니다. 이런 조건이 없어지면 남은 시간이 다시 줄어듭니다. 교대해도 진영 공용 시간은 유지됩니다. [4]

### 중앙선 반칙인데 상대가 공을 바로 들지 않아요.

정상 규칙입니다. 10.7.3은 **데드볼을 반칙 위치에서 상대 코트로 굴리고**, 이후 회수하도록 합니다. [5]

### 공을 잡았는데 팔이나 손이 안 보여요.

공 보유 중 추가 팔·손 표현을 제거한 버전입니다. 공 보유와 공격 기능은 별도로 처리됩니다. [5]

### 필살기의 작은 공들이 사라져요.
